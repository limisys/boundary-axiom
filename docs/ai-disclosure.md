# AI-assistance disclosure

The following sentence is the approved disclosure for the papers (Methodology or
Acknowledgments) and for the repository README.

**中文（定稿）**

> 本文的 Lean 证明草稿、文献初筛及代码重构使用了 AI 辅助工具（如大模型），所有数学推导、形式化核心逻辑及最终结论均由人类作者独立验证并承担全部学术责任。

**English**

> The Lean proof drafts, literature screening, and code refactoring in this work used AI-assisted tools (e.g., large language models). All mathematical derivations, core formalization logic, and final conclusions were independently verified by the human authors, who take full academic responsibility.

Placement rule: paper B §7 (Methodology/Acknowledgments); paper A §6
(Methodology/Acknowledgments); repository README under “Scope and honesty”.
Do not expand this into a claim about the tools' reliability.
