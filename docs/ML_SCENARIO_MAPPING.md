## 0. 全局映射词汇表(ML 语境的符号租用)

| 理论量 | ML 建议映射(每行皆假说) |
|---|---|
| κ(边界锐度) | 判别置信边界锐度:决策边界过渡带宽度倒数(如校准斜率/logit 尺度);或 margin 裕度操作化候选 |
| c₀(维护价) | 维持该锐度的代价:正则项强度、容量/算力/样本代价、精确度维护成本(对应过拟合压力) |

| σ*=1(无量纲临界) | 自洽条件:两代价比率被钉在 1 → 预测各类"最优平衡点"处的指数/比率关系 |

## 1. H0 · 单一假设(attribution presheaf / 稳定闭包纤维)
**EN**: attribution structure is a presheaf over causal interventions; the boundary is its stable closure fiber under cohesion.
**ML 映射**:
- 场景:把"输入扰动"当因果干预、把"训练反向传播/归因"当拉回(论文 LLM 映射无残留)。
- 检验设计(agent 协议):扰动已被接受事件,按 σ 分箱,测"翻转率随 σ→1 是否下降"(=A3 不可穿透判据的 ML 实例化)。
- 失败判据:翻转率与 σ 无关 → H0 在该体系不成立。

## 2. A1 因果闭包 / A2 归因函子 / A4 单势生成 / A5 最小作用量
- **A1(A2) 组合与函子性**:ML=干预(输入变换/扰动/反事实)与归因(梯度/消融/attention)应满足组合律与函子律。
  - 检验:多层扰动-归因交换律(perturb∘attr ≈ attr∘perturb)在强稳健模型上偏差小;`IG 路径独立/完备性`类同拉回。
- **A4 单势生成**:所有可观测量(锐度、熵、张力、广义力)是同一 V 的投影,非独立量。
  - ML:对同一模型族,鲁棒性代价/熵代价/泛化 gap 沿某一轴共变(单自由度);若需 >1 独立代价轴 → A4 不成立。
- **A5 最小作用量**:系统落在 V'(κ)=0。
  - ML:最优正则强度/最优校准点 = 使 V 最小;网格扫 (c₀,α) 应出现唯一最小值且满足 equipartition(见下)。

## 3. V(κ)=c₀κ+αC_F/κ · 势形式(强制非 ansatz)
**ML 场景映射表**:

| 场景 | κ 映射 | c₀ 项(锐度维护价) | α·C_F/κ 项(被排除熵价) | equipartition 预言 |
|---|---|---|---|---|
| 二分类(逻辑回归族) | logit 尺度/校准锐度 | 权重衰减 λ 或样本/容量代价 | 标签噪声/熵惩罚系数 | 最优 λ 处:维护价=鲁棒价,V 最小 |
| SVM/大间隔 | 间隔宽窄倒数 | 松弛惩罚 C 的成本侧 | 误分/边界熵侧 | 最优 C 使两侧平衡 |
| 深度网络 | 决策边界几何锐度(1/宽度) | 显式/隐式正则(SGD 隐 bias、权衰减) | 对抗/分布外风险价 | sharp-flat 平衡与鲁棒性最优点 |
| 校准/不确定性 | 置信斜率锐度 | 校准训练代价 | ECE/未覆盖区风险 | 最优温度处两侧平衡 |
| 样本复杂度 | κ ~ 每样本边界保持力 | 每样本训练成本 c₀ | 有限样本熵价 α | 样本数最优点存在且可反推常数 |

## 4. 共轭可观测量(H 与 F_κ,Legendre 对)
**EN**: H = ∂V/∂α = C_F/κ; F_κ = −∂V/∂κ; σ = σ₀ C_F²/H².
**ML**:边界熵 H(≈1/κ)与鲁棒力 F_κ 不应独立漂移——测 ECE(校准熵代理)与对抗翻转力,应沿同一 κ 轴反相关(单参数族)。σ=σ₀C_F²/H² 给出**张力↔锐度↔熵的闭式联立**,可直接回归验证斜率。

## 5. T1 · Critical Sharpness(机器检验 deriv_V_kappaStar)
**EN**: unique minimum κ\*=√(αC_F/c₀); maintenance=uncertainty price at κ\*.
**ML 场景**:最优正则强度预测 κ\* ∝ √(α/c₀):
- 场景 A(对抗训练):令 c₀=权衰减、α=对抗扰动预算权重 → 预测最优扰动强度~√(α/λ) 关系;
- 场景 B(标签噪声):噪声率↑→α↑→κ\* 应下移(边界应变钝/置信降),测最优锐度随噪声率的 √ 漂移;
- 失败判据:最优锐度与 √(α/c₀) 无单调关系。

## 6. T2 · Critical Tension(机器检验 sigmaStar_eq_one)
**EN**: σ\* = αC_F/C₀; logistic 核下 σ\*=1 ⟺ π²α=3C₀.
**ML 场景**:
- 校准-稳健平衡:π²α≈3C₀ 成立处,模型应处于"临界张力":校准与鲁棒性同时最优;
- Scaling 关联:若把 C₀ 当数据/容量规模、α 当正则预算,σ\*=1 预测规模与正则预算的**幂律配比**(联系 scaling laws 指数,可作为 S4 课题 3+15 对表的实测锚之一);
- 失败判据:在 (α,C₀) 平面上最优集不落在 π²α=3C₀ 附近。

## 7. T3 · Landau Bifurcation(数学推导,确定性计算确认)
**EN**: V(φ;r)=−rφ²+φ⁴;最小集在 r=0 由单点裂为两点 = "新模块装配"。
**ML 场景**:
- Grokking/延迟泛化:训练后期损失/表征发生二次分叉(记忆→泛化解);
- Double-descent 相变 / 相转移(grokking、mode splitting、模型合并冲突):控制参数 r=σ−1 扫过 0 → 最小集分裂;
- 容量涌现:随规模扫 r,泛化行为从单谷变双谷(两对称解)→ 模块/专家分化;
- 失败判据:扫 r 未见分叉或分叉非连续(一阶跳变而非对称二裂)。

## 8. T4 · Noether Conservation(代数芯机器检验)
**EN**: E=½M\dot μ²+½I\dot κ²+V(κ), dE/dt≡0("我是同一个我"=守恒荷)。
**ML 场景**:
- 训练动力学不变量:在满足 action 式的优化器中,存在守恒组合量(如动能-势能差沿轨迹守恒)→ 在真实训练日志(公开)上量测漂移;
- 持续学习/身份守恒:模型沿任务序列漂移但"自指一致性"(同输入自预测一致)守恒——permuted-MNIST/任务流上测;
- 失败判据:守恒量漂移超出数值噪声 → 该场景不守恒,理论需修订(这正是"可证伪"设计)。

## 9. T5 · Assembly Attractor(数学推导,确定性计算确认)
**EN**: σ_{n+1}=σ_n/(1+ε)+D → σ_∞=D(1+1/ε)。
**ML 场景**:
- 迭代扩容(模块/专家/LoRA 增量、ensemble、小模型迭代微调):每步扩容量 ε、需求 D → 张力收敛 σ_∞=D(1+1/ε),**预测扩展饱和平台高度**;
- 失败判据:实测扩展曲线平台与 D(1+1/ε) 系统性偏差(>量级)。

## 10. A3 · Boundary Definition / 不可穿透(agent 安全直接落点)
**EN**: boundary = stable closure fiber;further intervention no longer changes attribution(可干预但不可穿透)。
**ML/Agent 场景**:
- 鲁棒性-自我归因:扰动已接受事件,翻转率随 σ→1 降(论文协议,未跑);
- 自主边界(autonomy boundary,工作组核心题):agent 应停的"动作边界"= 归因不再被穿透之处 → 操作化为拒绝率/越权行为率随动作熵的平衡点;
- 失败判据:边界"穿透"(翻案/越权)与 σ 无关。
- 与"非干预预测"纲领衔接:在**公开 agent 评测与鲁棒性榜单**上预注册翻转率-σ 关系再量测(零干预)。
