## 三、设定变更的**实质**(需要您确认的核心)

```
旧设定:  统一边界公理  =  一条被【假设】的出发点
                          (在 Lean 里应写成 axiom)

实际:    统一边界公理  →  被【导出】为定义与定理
                          (Lean 层 axiom = 0)
```

**「统一边界公理」在 Lean 层不再是一条被"信奉"的公理,而是一个从
边界势 `V(κ) = c₀κ + απ²/(3κ)` 解析导出的数学对象。**

7 个 `def` 正是这个导出结构的骨架:

| # | def | 角色 |
|---|---|---|
| 1 | `V` | **边界势**(全部导出的源头) |
| 2 | `kappaStar` | 最小作用锐度 κ\* |
| 3 | `sigmaStar` | 张力 σ\* |
| 4 | `force` | 广义力 F |
| 5 | `hbin` | 二元熵 h(p) |
| 6 | `sig` | sigmoid σ(z) |
| 7 | `entropyDensity` | 熵密度 |

**⇒ 这是一个"单一势能函数 + 全部结论由其解析导出"的结构,本体论承诺最小**
(理论文档 §294 原话:"新增六条均非并列公理,而是从「边界势」这一单个对象解析导出,
符合纲领「**不新增本体论承诺**」的纪律")。
