# Boundary Programme — machine-checked formalization

Machine-checked Lean 4 formalization of a boundary as the fixed-point set of a
closure operator, a criterion as a threshold level set, and the conditions under
which the two coincide.

**Status:** research code and evidence release; papers are preprints, not
peer-reviewed. This repository is not a paper and does not claim that the
philosophical interpretation is machine-checked.

## Quick start

Requirements: `elan`, Python 3.10+, and a network connection for the first
Mathlib download.

```bash
# Lean toolchain + Mathlib cache + build
lake update
lake exe cache get
lake build

# Python checks
python3 -m pip install -r requirements.txt
bash scripts/ci_check.sh
```

A clean clone is expected to build all 71 modules and pass `scripts/ci_check.sh`.
The GitHub Actions workflow runs the same checks; a green CI run is the public
reproduction record.

### Offline audit (optional)

The author's original 9-step audit uses a prebuilt Mathlib package tree and
`scripts/build.py`; it is not required for normal use. If you have such a tree:

```bash
export ELAN_HOME="$HOME/.elan"
export MATHLIB_PACKAGES="/path/to/mathlib/packages"
python3 scripts/build.py --clean --jobs 4
```

The public CI does not depend on a machine-specific Mathlib path.

## What is machine-checked

- the seam: `Fix(c_{Lθ}) = S_θ` under the derived conversion
  `L(θ) = ln((2−θ)/θ)`;
- uniqueness of the description layer;
- the weak no-go: no gauge-invariant predicate depending only on the level
  selects a unique level;
- the type-level identification of three closure constructions;
- the A-module `C_H = π²/3` chain;
- the numerical reproductions in `scripts/repro_v3.py` and
  `scripts/repro_path_b.py` (independent of Lean artifacts).

## What is not claimed

- that all boundaries are closure fixed points;
- that the organizational boundary and the cognitive criterion coincide on the
  same system (only a conditional bridge and a converse counterexample are
  formalized);
- that the level is necessarily set by an external observer; the no-go is
  limited to level-only gauge-invariant predicates;
- empirical applicability; there is no real-system data;
- that this repository proves a philosophical thesis.

The papers state their own scope. When in doubt, read `docs/SCOPE.md`,
`docs/counts.md` and the paper's "what is not claimed" section.
