# BoundaryTheory — A-module Lean formalisation (group 1)

## What

This is **group 1** of the Lean layer. It contains a single file,
`BoundaryTheory.lean`:

- **928 lines**
- **33 theorems + lemmas** (27 theorems, 6 lemmas)
- **7 definitions**
- **0 sorry** (fully machine-checked)
- Built with **Lean v4.33.0** and **Mathlib v4.33.0**

## Build

```sh
cd code
lake build
```

This requires Lean 4.33.0 and the corresponding Mathlib; `lake-manifest.json`
is included so the exact dependency set is reproducible.

## Files & integrity

```sh
sha256sum -c SHA256SUMS
```

## Scope

This release contains **only group 1**. The corresponding paper is **not
published here**. Groups 2 and 3 are not included in this package; group 3
(the unified audit body) will be published only after the author's manual
reproduction of all machine-checked results and written notice.
