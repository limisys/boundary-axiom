2. Build evidence

The minimal core was built with the offline script:

MATHLIB_PACKAGES=/path/to/.lake/packages ./scripts/verify_offline.sh

Expected output:

PASS: 6 modules compiled (0 sorry / 0 axiom).

The six modules are:

  1. LocusVsBoundary
  2. ClosureFromInterventions
  3. ReportBridge
  4. ReportIdentityCore
  5. ReportCountermodelsCore
  6. ReportIdentity (umbrella import; no declarations)

Axiom audit: the load-bearing declarations depend only on [propext, Classical.choice, Quot.sound]. No sorry, no admit, no custom axioms.

The v1.0 UpClosed files are retained only under audit/. They are not imported by the v1.1 build. The audit proves UpClosed R ↔ R = Set.univ; citing v1.0 as a non-vacuous result would be an error.

4. Gate evidence

architecture/gate_reference.py is a standard-library finite-state reference. The current release adds the R6 wrapper and passes 14/14 protocol checks:

RESULT: 14/14 protocol tests passed
PASS: 14/14 protocol tests

Coverage:

  • G1: positive bundle accepted and committed; Moore + c_R = C.
  • G2: non-Moore family → REVIEW (R2).
  • G3: non-closure → REJECT (R1).
  • G4: c_R ≠ C → REJECT (R3).
  • G5: report outside R → REJECT (R4).
  • G6: version/evidence mismatch → REVIEW (R5).
  • G7: parent mismatch → REJECT (R7).
  • G7b: zero/multiple candidates → REVIEW (R6); one candidate accepted.
  • G8: simulated crash before atomic swap leaves head unchanged.
  • G9: action gate ALLOW/DENY.
  • G10: canonical Fix(c_I) is Moore and accepted.
  • G11: per-state threshold family is not Moore → REVIEW.
  • G12: Fix(c_R) of the threshold family is the threshold plus Ω.

This is a protocol check, not a production validation. It does not measure acceptance/rejection rates on a real task.

5. What is not in this ledger

  • No proof that the attribution presheaf induces the closure; see docs/OPEN_BRIDGE.md.
  • No uniqueness theorem for the level parameter w; the gate must take w as an input or adopt a separate selection principle.
  • No derivation of A7 or the potential form from the free category. The A-module is a separate model-class scope.
  • No production deployment or adversarial runtime test.
  • No peer review. The papers are preprints.

6. Reproduction notes

The Lean build requires Mathlib 4.33.0. A clean clone needs network on the first lake update / lake exe cache get; the offline script requires a prebuilt Mathlib package tree. The static site needs only Python 3 and a browser; MathJax is vendored under site/assets/mathjax.

Site build:

python3 site/build_site.py
python3 -m http.server 8793 --bind 127.0.0.1 --directory site

Gate:

python3 architecture/gate_reference.py
