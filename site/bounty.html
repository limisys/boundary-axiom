This corpus is released so that it can be falsified. A construction that survives its own checks beats an opinion that does not. Four claims are stated precisely enough to be attacked; each is listed with the thing that would defeat it.

Submit a counterexample What is claimed →

Open targets

  • C1 · Report = fixed family. On a Moore report family, the report family is exactly the fixed-point family of cR. Defeated by: a reported set that is not closed, or a closed set that is not reported, inside the stated class.
  • C2 · The family determines the closure. Two distinct closure operators on the same domain with the same fixed-point family. Defeated by: an explicit pair, with the differing value exhibited.
  • C3 · The gate is sound and complete for R1–R7. Defeated by: a finite-state trace that passes the reference gate and violates joint commit consistency, or the reverse.
  • C4 · Weak equivalence. cR = cR′ exactly when R = R′. Defeated by: a pair of report families with equal closures and unequal members.

Claims outside this list — the attribution bridge, a unique level w, A7 from category theory, production behaviour — are stated as open on the open bridge page. Refuting them is welcome, but they are not scored as counterexamples to the core.

What counts as a submission

  • Minimal. The smallest object that fails: one family, one trace, one pair. A large construction that happens to fail is harder to judge and is asked to be reduced.
  • Machine-checkable. A Lean file that builds against this repository, or a Python script that runs against architecture/gate_reference.py. Prose is read but not scored.
  • Reproducible. The command that exhibits the failure, and the output you obtained.
  • On the record. State the claim ID you are attacking and the verdict you expect.

How it is judged

Three outcomes, published as they are decided. Accepted: the construction reproduces and defeats the claim as stated. Refuted: the construction does not do what it claims, with the reason given. Out of scope: the target is not a claim this corpus makes, with the boundary restated. A rejected construction is recorded too, unless the submitter asks otherwise.
